## 0  What this register is, and what it is not

The brief sets the order of authority for Works Management:

1. **the owner's uploaded Works Management files** ← the four files in `USER_SOURCE/`
2. actual project information
3. existing project documentation
4. previously generated Works Management material ← **WM1**

So **nothing of the owner's has been corrected, re-derived, rounded or rebuilt.**
The BOQ, the rates, the cost build-up, the durations, the dates and the activity
structure are published exactly as supplied, straight out of the owner's own files
(`Cost/` and `Programme/USER_MASTER_CONSTRUCTION_SCHEDULE_R0.*`).

**Every arithmetic statement in this register is checked, not asserted.**
`Scripts/wm2_user_package.py` re-adds the owner's own columns and writes the result to
`QAQC/WM2_SOURCE_AUDIT.txt`. Run it and the figures below either reproduce or they do not.

**This register only records where the owner's material and the project master
disagree. It resolves nothing.** Every row below is for the owner to rule on.
That is deliberate: the master's rule is that a conflicting value is `[UNRESOLVED]`
until a person decides, and the brief's rule is that an inconsistency is preserved,
flagged and documented, never silently redesigned.

**WM1 is not overwritten.** It stays in place as the quantity-derivation package it
always was. Where the two overlap, the owner's figure is the one to price from.

## 6  One WM1 item that the project has now superseded

`SP-06` in the WM1 bill reads *"RC lintels over openings, **200 × 150 PROVISIONAL —
design required**"*, tagged `[N]`, with the note that **no lintel design existed
anywhere in the project**.

That is no longer true. **SP-B2** (10 September 2026, master **A.4.8** and **H.12**)
designs lintel **L1** to IS 456 — **190 × 150, M30 / Fe500, 2-T10 bottom, 2-T8 top,
T6 links @ 150, bearing 200 each end**, one type over all eleven openings — and closes
**WM-V5**. The tie detail closes **WM-V11**.

L1 is **190 wide, not the provisional 200**, so the WM1 lintel volume is over-measured
by 5 %. WM1's own run of lintel — eleven openings, each clear width plus 200 bearing
each end — is **17.000 m**, so:

| | |
|---|---:|
| `SP-06` provisional, 200 × 150 | 17.000 × 0.200 × 0.150 = **0.510 m³** |
| **L1 as designed, 190 × 150** | 17.000 × 0.190 × 0.150 = **0.485 m³** |
| Over-measure | **0.026 m³ of M30** |

**`SP-06` is left exactly as it stands in the WM1 bill and is not re-measured here** —
WM1 is a preserved revision, and 26 litres of M30 changes nothing. It is recorded so
that the next revision of the bill picks up L1, with its reinforcement, rather than a
provisional section with none.
