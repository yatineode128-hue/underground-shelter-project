## 1. Reference model

`current/staad/Underground_Structure_WITH_LOADS_worked_example (4).STD` — the reconciled Phase 2
Rev A + M1 underground box plate model — is the **MEDIUM / reference** mesh of this study. It was
inspected (not edited) to determine its actual mesh.

The file has no `SURFACE INCIDENCES` / `GENERATE MESH` command — it is a fully explicit,
hand-built structured grid. Its own header states the numbering rule:

```
n = (k-1)*310 + (i-1)*10 + j    i = X index 1..31, j = Z index 1..10, k = Y index 1..7
```

Parsing `JOINT COORDINATES` against this rule and cross-checking every `ELEMENT INCIDENCES SHELL`
entry confirms it exactly: the model is one global structured grid —

* **X:** 31 stations, 0.300 – 21.700 m, spacing 0.525 – 1.000 m (avg. 0.713 m)
* **Z:** 10 stations, 0.300 – 5.900 m, spacing 0.525 – 0.700 m (avg. 0.622 m)
* **Y:** 7 stations, 0.300 – 4.250 m, spacing exactly 0.6583 m (6 equal wall rows)

— with panels (mat, roof, 4 external walls, W5, W6, W7) built from 4-node rectangles cut from
this grid, and three rectangular voids in the roof panel only: the stair-shaft void
(X 15.0–18.2, Z 0.3–4.01), and the two 1.4 m escape shafts (X 1.35–2.75 / X 19.2–20.6, both
Z 1.35–2.75). Mat: 270 elements (no holes). Roof: 238 (270 − 32 hole cells). Four exterior walls:
180 + 180 + 54 + 54. W5: 54. W6, W7: 54 each. Total 1138 elements, 1113 joints — matching the file
exactly, corner mat-spring values (`KFY` 6891/8269/7219/8663) and all six `LOAD 6` row pressures
(82.71 → 32.0 kN/m²) reproduced to the last decimal from first principles (see §3). This confirms
the grid model below is the actual mesh logic already in the reference file, not a guess.

**Average element size of the reference (MEDIUM) mesh ≈ 0.6–0.7 m** (both directions, and the
6-row wall discretisation), which is technically reasonable for a hand-built plate model of a
20.8 × 5.0 m box with 5–6 m tall walls (span/element ≈ 8–35), fine enough to resolve blast-driven
bending gradients near wall bases and openings without being unworkable by hand.

## 2. Mesh selection

Because the reference mesh is a structured grid, not a single scalar "element size", COARSE and
FINE were generated by operating directly on the reference grid lines (X, Z, Y arrays), which is
the only way to guarantee identical geometry:

* **FINE** — insert one new grid line at the exact midpoint of *every* interval in the reference
  X, Z and Y arrays. This is a uniform **h/2 refinement**: every reference grid line is kept, so
  the FINE geometry (walls, openings, corners) reproduces the reference exactly, just more finely
  subdivided. Element count is therefore exactly 4× the reference in every 2-D panel.
* **COARSE** — remove alternating reference grid lines, **except** any line that defines the outer
  box boundary, a W5/W6/W7 centreline, or an opening edge (stair shaft, either escape shaft) —
  those are always kept so the coarse mesh has pixel-identical geometry to the other two. Where an
  opening or a wall centreline forces an odd number of reference intervals in a bay, one interval
  in that bay could not be halved cleanly and was left un-doubled — a small, local, documented
  mesh-size variation, not an error (see §5).

This gives a genuine h, ~1.8h, h/2 sequence — FINE is an exact refinement of MEDIUM (the cleanest
possible pair for a convergence check), and COARSE is unambiguously coarser throughout.

|---|---:|---:|---:|---:|---:|

## 3. What was held identical, and how re-derived quantities were computed

Held byte-identical across all three models: M1 geometry (box 22 000 × 6 200, shaft
15200–18000, W6/W7 400 thk, ESC 2 at 19 900, all other M1 values), wall/roof/mat thicknesses,
internal walls, all three openings, M35 material properties, subgrade modulus (k_s = 100 000
kN/m³), all 11 load case definitions and magnitudes, and all 5 load combinations (same case
numbers, same factors, copied verbatim).

Two quantities are **mesh-density-dependent by definition** and were re-derived per mesh from the
reference model's own formulas — not re-guessed, not left at the reference values:

* **Corner mat-spring `KFY`.** STAAD's `ELASTIC MAT` auto-computes each node's tributary area from
  the mesh; the reference model additionally restates an explicit `KFY` at its four mat corners
  (`FIXED BUT` replaces `ELASTIC MAT` there). Back-solving the reference's own four values
  (6891/8269/7219/8663) reproduces them exactly with `KFY = k_s × 0.25 × Δx_edge × Δz_edge`, where
  Δx_edge/Δz_edge are the corner's adjacent mat element widths. The same formula, applied to each
  new mesh's own corner element widths, gives Coarse 27563/16538/28875/17325 and Fine
  1723/2067/1805/2166 kN/m.
* **`LOAD 6` (EP1) earth+water row pressures.** The reference model applies this as a stepped
  approximation — one uniform pressure per vertical row of wall elements, equal to the pressure at
  that row's mid-height. Fitting the reference's own 6 (depth, pressure) pairs gives
  **p = 15.4071 × depth − 10.8198 kN/m²** (depth = 6.700 − Y, i.e. below the ground-level datum),
  R² ≈ 1, max residual 0.01 kN/m² — i.e. this is exactly the linear formula the reference model was
  built from, just rounded to 2 dp. The same formula was resampled at each new mesh's own row
  mid-heights: 3 rows for Coarse (77.64/57.36/37.07), 6 for Medium (unchanged), 12 for Fine
  (85.25 → 29.46). All other loads are uniform pressures (kN/m²) applied to the same physical
  panels, so they needed no adjustment — pressure intensity is mesh-independent; only which
  (new) element IDs cover a given panel changes.

## 4. Definition of "effective force" used in this study

STAAD.Pro does not print a field literally called "effective force" for shell/plate elements. For
this study, **"effective force" means the STAAD.Pro Von Mises effective stress at the plate
centroid**, S<sub>VM</sub> = √(S<sub>X</sub>² − S<sub>X</sub>S<sub>Z</sub> + S<sub>Z</sub>² +
3S<sub>XZ</sub>²), computed from the plate's in-plane stress resultants S<sub>X</sub>,
S<sub>Z</sub>, S<sub>XZ</sub> (STAAD `PRINT ELEMENT STRESS` / GUI Von Mises contour), **units
kN/m²**. It is reported **alongside**, not instead of, the governing local bending moment
(M<sub>X</sub> or M<sub>Z</sub>, kN·m/m width — the quantity actually used by the
`START CONCRETE DESIGN` block). Both are combined-action scalars suitable for comparing
bending + membrane response across meshes of different density, and both are used **consistently
across all three models** once analysis is run.

## 6. Recommended mesh — provisional, pending §5

Pending actual results, the **Medium (reference) mesh is provisionally recommended** for design
use: it is the mesh the entire hand-calculation cross-check in master Part B was built against,
and Fine exists specifically to confirm (or refute) that Medium's results are already
mesh-converged. If §5 shows Medium→Fine change is small, adopt Medium (cheaper to run, already
cross-checked by hand). If it is not small, Medium is not yet converged and Fine (or a further
refinement) should be adopted, and Part B's hand checks revisited.

## 8. Limitations

* **No STAAD.Pro analysis has been run.** This is a file-generation and file-level validation
  study only; §5's table is a template awaiting real results.
* COARSE has one local un-doubled interval in a few bays where an opening/centreline boundary
  forced an odd reference-interval count (documented in §2) — this is a normal, unavoidable
  consequence of preserving exact opening geometry while coarsening a non-uniform hand-built mesh,
  not a modelling error.
* The `EP1` and `KFY` re-derivations in §3 reproduce the reference model's own formulas to within
  rounding (≤0.01 kN/m² residual on the pressure fit); they are not independent geotechnical
  recalculations and carry the same `k_s` **[ASSUMED]** tag as the reference model (master A.6).
